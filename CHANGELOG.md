# Changelog

## [1.0.0]

- First production-ready KnOwl release.
- Extracted contract design, promotion, distribution, runtime catalog, storage, security, Web UI, bootstrap, and worker behavior into reusable `KnOwl.*` libraries.
- Added thin Control Plane and Runtime host samples with EF Core migrations kept in the host projects.
- Added multi-target support for `net9.0` and `net10.0`.
- Added SQL Server integration and end-to-end distribution validation for push and pull runtime flows.
- Prepared NuGet package metadata for all packable KnOwl libraries.

## [0.0.0]

- Initial KnOwl extraction baseline.
